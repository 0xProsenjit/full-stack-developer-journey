# JavaScript Array Iteration Methods

This repository contains examples and practice code for important JavaScript array iteration methods.

## Included Files
* `every.js` - Checks if all elements in an array pass a test.
* `filter.js` - Creates a new array with elements that pass a test.
* `find.js` - Returns the value of the first element that passes a test.
* `findIndex.js` - Returns the index of the first element that passes a test.
* `forEach.js` - Executes a provided function once for each array element.
* `map.js` - Creates a new array by transforming every element in an array.
* `reduce.js` - Reduces the array to a single value.
* `some.js` - Checks if at least one element in the array passes a test.
